Querygauge Privacy Policy

Effective November 5, 2026. This policy covers Querygauge, a private tool that only I, Teimur Gasanov, use.

Data access

Querygauge signs in to my own Google Ads account with the scope https://www.googleapis.com/auth/adwords. It reads search volume, ad competition and top-of-page bid estimates for keywords that I give it. It does not read campaigns, billing details or the data of other people.

The sign-in also grants the scope https://www.googleapis.com/auth/cloud-platform, because the gcloud sign-in command requires it. Querygauge does not call Google Cloud APIs.

Use

I use the data only for keyword and market research. I do not use it to advertise to any person, and I do not sell it.

Storage

Querygauge has no server. Its OAuth credentials are in a file on my computer that only my user account can read. Results are in local files until I delete them.

Sharing

I do not give the data to third parties, with one exception. I can run Querygauge through an AI coding assistant, which processes the keywords and the results. The assistant does not receive the OAuth credentials.

The use of information from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Remove access

To revoke access, remove Querygauge at Google Account permissions. To remove the stored data, delete the local files.
