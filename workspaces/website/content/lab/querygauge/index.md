# Querygauge

Querygauge is a private command-line tool. It reads search volume and ad competition from the Google Ads API for keywords that I give it.

I use it for personal market research. It saves the results to a local file. It only reads data, and it cannot change campaigns, ads or budgets. Only I can sign in to it.
